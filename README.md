# Internship Mini Project – Data Analysis & Naive Bayes Classification

This repository contains Jupyter notebooks developed during my internship mini-project. It demonstrates basic data handling, visualization, and the development of a Naive Bayes classifier using Python.

## Project Overview

The mini-project was aimed at:
- Understanding the structure and distribution of the provided dataset
- Extracting and visualizing key variables
- Building a **Naive Bayes model** for classification
- Evaluating the model using **accuracy score** and **confusion matrix**


## Notebook Details

- **MiniProject.ipynb**  
   - Data preprocessing and visualization  
   - Naive Bayes classifier implementation using `scikit-learn`  
   - Accuracy score and confusion matrix output

- **aruna.ipynb**  
   - Raw data loading  
   - Column selection and filtering  
   - Basic plotting using `matplotlib`

## Technologies Used

- Python 3.x  
- pandas  
- matplotlib, seaborn  
- scikit-learn  
- Jupyter Notebook

## Data Note

> The uploaded dataset is an **example** to demonstrate how the code works.
